# 经验（Lessons）

> 一条经验 = 现象 + 根因 + 以后怎么做。只有「以后」能被执行才算经验。

## 技术类

### 命令里出现反引号会被 shell 当命令替换（2026-10-20）
- 现象：拼接的文本丢内容，终端报 `xxx: command not found`。
- 根因：bash 双引号内反引号仍执行命令替换。
- 以后：含反引号或代码片段的文本，**先写文件再让程序读**，不在 shell 里内联。
- 反例：单引号内的反引号安全。

### 台账行与决策行不能复用同一段文本（2026-10-20）
- 现象：同一批内容写进两个表，其中一个表出现重复行 + 日期格式不对。
- 根因：两个表字段与格式不同，复用模板导致不匹配。
- 以后：**一个目标一段文本**，写完对每个目标单独校验（行数 / 唯一性 / 格式）。
- 适用：批量写多文件、多表。

### 采集成功 ≠ 交付成功（2026-10-19）
- 现象：竞价采集 124/124 全成功，但看板数据停在三天前，线上也是旧数据。
- 根因：只做了「落盘」，没做「同步到消费端 + 发布 + 线上校验」。
- 以后：采集类任务必须看**消费端最后更新时间**；同步链路要单独立脚本并做线上校验。
- 适用：任何「采集 → 展示」两段式系统。

### 粗口径字段不能拿来数次数（2026-10-19）
- 现象：池子记炸板 1 次，逐笔数据还原是 2 次。
- 根因：池子字段是同名事件合并后的粗口径。
- 以后：粗口径只做筛选分层，**计数用细口径**。
- 反例：官方口径与明细对不上时，先确认哪一个是「计数定义」。

## 方法类

### 「我写了」≠「它生效了」（2026-10-19）
- 现象：规则写进文件 24 小时内，同类错误又犯一次。
- 根因：只改了规则文本，没落到「做这件事的那一步」。
- 以后：每条规则必须能回答「谁、在哪个动作、因为这条规则做了什么不同的事」；答不出来就是没落地。
- 适用：所有 SOP、纪律、清单类文档。

### 有现成的就抄，别从零设计（2026-10-18）
- 现象：自己设计的界面要返工三轮，抄成熟项目一次过。
- 根因：人家迭代过、踩过坑。
- 以后：先找同类实现，照抄结构与文案，跑起来再改。
- 边界：能抄壳（布局 / 交互 / 文案），不抄芯（业务口径 / 判定逻辑）。

### 先问渠道，再给路径（2026-10-19）
- 现象：给三个取消订阅入口，一个都不对，白点三轮。
- 根因：支付渠道决定入口（苹果 IAP 只能在苹果设备取消）。
- 以后：涉及「在哪操作」的问题，先问清平台 / 渠道，只给对路的那一条。

## 判断类

### 他要的是「看得见」，不是「已经接进来了」（2026-10-19）
- 现象：数据接入完成即汇报，被要求「上看板」。
- 以后：新数据接入必须同步回答「在哪能看见」，否则不算完成。

## 维护规则

- 每条必须有「以后」一行，否则不收。
- 同一根因出现 3 次以上，升级成 `03-taboos.md` 的硬约束。
- 超过 6 个月没被引用的，移到归档，不留在主档。
